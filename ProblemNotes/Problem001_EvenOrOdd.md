# Problem 001: Even or Odd

## Problem
Determine whether an integer is even or odd.

## Input
One integer.

## Expected Output
Display whether the number is even or odd.

## Approach
1. Read the user's input.
2. Validate that it is an integer.
3. Calculate the remainder when divided by 2.
4. If the remainder is zero, the number is even.
5. Otherwise, the number is odd.

## Test Cases
- Input: 4 -> Even
- Input: 7 -> Odd
- Input: 0 -> Even
- Input: abc -> Invalid input
